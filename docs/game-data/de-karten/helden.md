# Helden – Deutsche Originalkarten

> **Quelle:** Hochauflösende Scans der deutschen Original-Heldenkarten (Descent 2. Edition).
> Namen, Werte und Texte (Heldenfähigkeit / Heldentat) sind **1:1 von den Karten** abgelesen
> (OCR + visuelle Kontrolle) und ersetzen die früheren Community-Übersetzungen.
> Kartenbilder: `public/cards/de/heroes/<id>.webp` (Vorderseite) + `<id>-back.webp` (Flavor-Seite).

**Bestand:** 60 Helden (13 Heiler, 18 Krieger, 16 Kundschafter, 13 Magier) – je Vorder- + Rückseite.
