## Übersicht

Reisekarten (Travel Cards / Road Event Cards) werden zwischen Szenarien gezogen.
Sie können positive oder negative Ereignisse auslösen oder Nebenszenarien (Side Quests) einleiten.

**Ablauf:** Nach Abschluss eines Szenarios zieht eine Seite (Helden oder Overlord) eine Reisekarte.
Dadurch kann ein Nebenszenario freigeschaltet werden, das vor dem nächsten Hauptszenario gespielt werden kann.
