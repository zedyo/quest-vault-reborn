# Descent 2. Edition – Helden-Klassen

**Status:** Grundspiel-Klassen vollständig validiert (v1.1.1); Erweiterungs-Klassen ausstehend  
**Quelle:** any2cards/d2e, BGG, offizielle Karten-Scans  
**Zuletzt aktualisiert:** 2026-06-13

---

## Wichtige Hinweise

- Jede Klasse gehört zu einem Archetyp (Krieger, Heiler, Magier, Späher)
- Jede Klasse hat ein Startdeck (enthält immer eine Startkarte, die kostenlos ist)
- Weitere Fähigkeiten werden mit XP erworben
- Beschwörungs-Begleiter (Summoned Companions) haben eigene Werte-Karten und werden wie kleine Monster behandelt
