# Quellen

Verdichtete Zusammenfassungen ingestierter Quellen. Beim Ingest liest der Agent
eine Quelle (externes Dokument, Spezifikation, Datendump, Karten-Scan,
Gesprächsverlauf), schreibt hier eine Zusammenfassungsseite und verlinkt sie mit
den betroffenen [Entitäten](../entities/) und [Konzepten](../concepts/).

Typischer `type`-Wert: `Source Summary`. Belege zur Ursprungsquelle gehören unter
`# Citations` (siehe [Schema](../schema.md)).
